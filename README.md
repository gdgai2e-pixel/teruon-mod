# Teruon — мод для Minecraft Java (Fabric 1.21.1)

ИИ-спутник Teruon (OpenRouter). Летает за тобой, телепортируется, выдаёт предметы, говорит голосом -> текст.

## Сборка
1. Нужен JDK 21.
2. В папке проекта один раз: `gradle wrapper --gradle-version 8.8` (или открой проект в IntelliJ IDEA — он сам всё настроит).
3. `./gradlew build` -> готовый мод: `build/libs/teruon-1.0.0.jar`
4. Закинь jar + Fabric API в папку mods (Fabric Loader 0.16+).
   Для теста из IDE: `./gradlew runClient`

## Настройка
- В игре: `/teruon config` -> вставь ключ OpenRouter (sk-or-...), при желании поменяй модели.
- Файл настроек: `config/teruon.json`.

## Управление
- ПКМ пустой рукой по Teruon — взять в руку. ПКМ предметом Teruon — поставить обратно.
- Предмет Teruon есть и в творческом инвентаре (вкладка «Инструменты»).
- **M** — «Говори!»: говоришь, после паузы речь превращается в текст в чате, Teruon отвечает.
  Повторное нажатие M — закончить запись раньше.
- Бить Teruon нельзя.
