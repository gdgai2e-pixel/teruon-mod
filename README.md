# Teruon — мод для Minecraft Java (Fabric 1.21.1)

ИИ-спутник Teruon (OpenRouter). Летает за тобой, телепортируется, выдаёт предметы, говорит голосом -> текст.

## Сборка
1. Нужен JDK 21.
2. В папке проекта один раз: `gradle wrapper --gradle-version 8.8` (или открой проект в IntelliJ IDEA — он сам всё настроит).
3. `./gradlew build` -> готовый мод: `build/libs/teruon-1.0.0.jar`
4. Закинь jar + Fabric API в папку mods (Fabric Loader 0.16+).
   Для теста из IDE: `./gradlew runClient`

## Настройка
- В игре: `/teruon config` -> вставь ключ OpenRouter (sk-or-...), при желании поменяй модели.
- Файл настроек: `config/teruon.json`.

## Управление
- ПКМ пустой рукой по Teruon — взять в руку. ПКМ предметом Teruon — поставить обратно.
- Предмет Teruon есть и в творческом инвентаре (вкладка «Инструменты»). Выкинешь его (Q) — он оживёт и полетит рядом.
- **Зажми V** — «Говори!»: говоришь, отпускаешь V — речь превращается в текст в чате, Teruon отвечает.
- Бить Teruon нельзя.
- Без микрофона: **/t привет** (или `/teruon say привет`) — написать Teruon текстом.
- Обычные сообщения в чате уходят Teruon, пока он у тебя в руке или летает рядом. Чтобы написать другим игрокам — начни сообщение с `!`. Отключается в `/teruon config`.
- Проблемы с голосом: `/teruon mic` покажет, видит ли игра микрофон.
- Достаточно написать в чат имя: **привет теруон** — сообщение уйдёт Teruon, даже если он далеко (но тогда он только отвечает, а предметы выдать и телепортироваться не может).
